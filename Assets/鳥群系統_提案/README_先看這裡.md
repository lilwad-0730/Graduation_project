# 鳥群系統（提案版）

**這是提案，不是取代。** 組員原本的 `BirdEnemy` / `IndividualBirdEnemy`（荒原那 57 隻）
一根寒毛都沒動，現在照常運作。這個資料夾裡的東西只是**額外多出來的一團鳥**，
散在天上繞，看得到、追不到、不會傷人。

等大家同意了，這個資料夾**有能力接手**舊鳥群的工作，而且是一鍵的事，
隨時可以一鍵還原。在那之前什麼都不會變。

## 為什麼要做這團

荒原原本的 57 隻鳥掛在 `BirdEnemy` 底下，世界 Y 只有 **1.3–7.4**，
差不多就在她眼睛的高度；而且 `detectionRange = 10`，要玩家走進 10 公尺
才會動作。在那之前牠們只是一排幾乎不動的黑點。

結果是：**玩家從來沒有「看到鳥群」**，只會突然被俯衝。
分鏡 Q5-S5「鳥影」→ Q5-S6「她抬頭」那一拍，在遊戲裡是不存在的。

這團補的就是那一拍。等舊的那批真的撲下來，玩家才知道剛剛天上那些是什麼。

---

## 動法：散落，不規則

不是一圈排整齊的鳥。

- **散落**：每隻在一塊 30 × 10 公尺的區域裡各自找位置，高低遠近都不同，
  大小也各差三成（有大有小才像散在不同距離）。
- **各繞各的**：每隻有自己的小圈（半徑差 ±45%）、自己的速度（差 ±35%）。
- **不規則**：路徑再疊三層 Perlin 噪聲——角度忽快忽慢、圈忽大忽小、
  每隻再各自亂飄。**沒有兩隻走同一條線，同一隻也不會走第二遍同樣的路。**

## 軸心永遠在她身上

整團的軸心鎖在玩家的 `transform`（不是鏡頭）。她走到哪、跳多高，這團就跟到哪。

所有散落位移在生成時會**扣掉平均值**，所以「軸心的中點」在數學上就是玩家本人，
不管牠們飄得多亂，整團都不會漂走。離線驗算過：鳥群幾何中心相對軸心的偏差
平均 0.78 公尺、最大 2.75 公尺。

`scatterCenter` 預設 `(0, 8)`：軸心跟著她，但整塊散落區抬高 8 公尺在她頭上。
設成 `(0, 0)` 就是完全貼在她身上——只是那樣會有鳥從她腳下鑽過去，
`minHeightAbovePlayer` 這道安全網會把牠們頂回地面以上。

## 大家同意之後，怎麼接手

在 `desert` 場景選中 `鳥群_提案版`，Inspector 找到 **FlockTakeover**，
右鍵這個元件：

| 選項 | 做什麼 |
|---|---|
| **① 接手：關掉舊鳥群、開啟新鳥群攻擊** | 把 `BirdEnemy` 整組 `SetActive(false)`，並打開新鳥群的俯衝攻擊 |
| **② 還原：把舊鳥群開回來** | 全部復原，新鳥群回到不攻擊的狀態 |
| **③ 只看狀態，不動任何東西** | 在 Console 印出現在是誰在運作、各有幾隻 |

也可以勾 `takeOverOnStart`，之後每次進遊戲自動接手。
**在大家點頭之前請保持不勾。**

### 接手 ≠ 刪除

接手只是把舊鳥「關掉」，**場景檔裡那 57 隻一個都沒少**，還原就整組回來。
真的要永久換掉是另一件事——要等大家決定之後，由人手動刪，不是這支腳本的工作。

## 攻擊模式做了什麼（`attackEnabled` 打開時）

每隔 `attackInterval` 秒挑一隻脫隊 → 播 `worried` 叫聲警告 `warningSeconds` 秒
→ 以 `diveSpeed` 俯衝向她當下的位置 → 命中就觸發重生 → 拉起歸隊。

判定完全沿用專案既有的規則，沒有自己發明：

- `PlayerShield.IsShieldActive` → 護盾擋下，不算命中
- `PlayerPetrification.IsGodMode` → 無敵，不觸發
- `PlayerRespawnSystem.IsAnyRespawning` / `IsPlayerMovingAfterRespawn` → 重生中、剛重生還沒動，不攻擊
- `UmbrellaZone.IsPlayerUnderUmbrella` → 躲在傘下，不攻擊
- 命中 → `PlayerRespawnSystem.TriggerRespawn()`

## 幾件不會出事的事

- 生出來的鳥會被**拔掉所有 Collider 與 Rigidbody**，永遠不會物理性地碰到玩家。
  攻擊命中是用距離判定，不靠碰撞體。
- 調暗用 `MaterialPropertyBlock`，**不碰共用材質**，所以不會把組員的鳥一起改色。
- 用 `Time.deltaTime`（不是 unscaled），開設定選單暫停時鳥也跟著停。
- 深度 `z = 0.3`：荒原的背景在 0.5、玩法在 0，所以這團在天上、在背景前面，
  不會擋住任何玩法物件。
